How this works, and what it can't tell you

A GitHub Actions job reads six live LTA traffic cameras — three at each checkpoint — and asks Claude to rate how stopped the traffic looks in each direction. Those ratings are combined into one score per checkpoint.

It cannot tell you a waiting time. A still photograph shows how heavy a queue looks, not how fast it is clearing, so there is no honest way to turn it into minutes. Any minutes shown here are driving time estimated from straight-line distance — never queue time.

Driving estimates use straight-line distance at an assumed average speed, not a routed journey, so they under-read real road distance. Public holidays are not accounted for in the fallback patterns.
